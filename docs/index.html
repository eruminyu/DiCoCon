나만의 콘은 무제한으로!

PC에서 너무 작게 보이는 디스코드 기본 이모지와 부족한 스티커 슬롯을 디코콘(DiCoCon)으로 해결하세요. 채팅창에 이모지나 :콘이름:을 입력하면 내 닉네임과 프로필 사진 그대로 큼직한 이미지를 전송합니다.

🏠 내 서버에 봇 초대하기 (서버 공용) 👤 내 계정에 앱 추가하기 (모든 서버·DM용)

* 입력하면 위의 두 초대 버튼에 즉시 반영되며, 필요한 권한이 자동으로 설정됩니다.

마스코트 코코(CoCo) 📥 봇 프로필용 이미지 받기

"작아서 안 보이던 이모지, 이제 큼직하게 보내요!"

디코콘만의 편리한 기능

답답했던 이모지 크기와 스티커 개수 제한 없이 자유롭게 대화하세요.

🔍

기본 이모지 자동 확대

채팅창에 커스텀 이모지 1개만 단독으로 입력하면 내 닉네임과 프로필 사진 그대로 128px 고화질 큰 이모지로 깔끔하게 바꿔줍니다.

💬

:콘이름: 빠른 전송

서버 스티커 슬롯 제한에 얽매이지 마세요. 등록된 커스텀 콘을 기본 이모지 형식 그대로 :바부: (또는 ;바부)로 입력해 0.1초 만에 바로 보낼 수 있습니다.

🌐

어디서나 /콘 초성 검색

봇이 없는 다른 서버나 친구와의 개인 DM에서도 /콘 초성 자동완성(ㅂㅂ ➔ 바부)과 /이모지확대를 사용할 수 있습니다.

⚡

우클릭 한 번으로 콘 저장

채팅방에 올라온 마음에 드는 짤이나 이모지를 우클릭 ➔ 앱 ➔ 콘으로 저장만 누르면 즉시 내 콘 목록에 추가됩니다.

직접 독립된 봇으로 운영하고 싶다면 아래 가이드를 순서대로 따라 해보세요.

1단계: 디스코드 개발자 포털에서 봇 토큰 발급받기

  1. Discord Developer Portal에 접속해 우측 상단 [New Application]을 눌러 앱(예: 디코콘)을 생성합니다.
  2. 좌측 메뉴 [Installation] 클릭:
    • Installation Contexts에서 User Install과 Guild Install을 모두 체크합니다.
    • Default Install Settings에서 Guild Install에는 applications.commands, bot 스코프와 Manage Webhooks, Manage Messages 권한을 추가하고 저장합니다.
  3. 좌측 메뉴 [Bot] 클릭:
    • [Reset Token]을 눌러 발급된 토큰을 복사해 .env 파일의 DISCORD_TOKEN= 뒤에 붙여넣습니다.
    • 아래로 스크롤해 Privileged Gateway Intents의 ✅ MESSAGE CONTENT INTENT를 반드시 켜고 저장합니다.

2단계: 리눅스 서버(Oracle Cloud 등)에 24시간 올려두기

포함된 install_linux.sh 스크립트를 실행하면 파이썬 가상환경 설치부터 systemd 자동 재시작 백그라운드 서비스 등록까지 한 번에 완료됩니다.

방법 A. 일반 리눅스 서버 (원클릭 자동 설치)

chmod +x install_linux.sh && ./install_linux.sh

방법 B. Docker가 설치된 서버 또는 NAS

docker compose up -d --build

실시간 작동 로그 확인 명령어

sudo journalctl -u discord-conbot -f

3단계: 별도 서버 없이 내 윈도우 PC에서 바로 쓰기

  • 일반 실행 (콘솔 창 확인용): 폴더 내 실행.bat 더블클릭
  • 창 없이 조용히 백그라운드 실행: 백그라운드_실행.vbs 더블클릭
  • 컴퓨터 켤 때마다 자동 실행하기: Win + R 입력 후 shell:startup 실행 ➔ 열리는 시작프로그램 폴더에 백그라운드_실행.vbs의 바로가기를 넣어두면 자동 시작됩니다.
  • 백그라운드 종료: 백그라운드_종료.bat 더블클릭
